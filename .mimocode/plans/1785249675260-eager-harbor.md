## Scoring Table Design

The scoring table will be a CSS grid of rows, styled like a tournament bracket/HUD:

```
┌─────────────────────────────────┐
│   TEKKEN RIVALS 2™ PRIME FINALS │
│                                 │
│   1 место ··············· 11    │
│   2 место ··············· 10    │
│   3 место ···············  8    │
│   4 место ···············  7    │
│   5-6 место ·············  6    │
│   7-8 место ·············  5    │
│   9-12 место ············  4    │
│   13-16 место ···········  3    │
│   17-32 место ···········  2    │
│   33+ место ·············  1    │
│                                 │
│   Топ 8 → PRIME FINALS          │
│   Round Robin система           │
└─────────────────────────────────┘
```

- Place names on left (white, Rajdhani)
- Dots/dashes as visual connector (faded)
- Point numbers on right (gold #fbbf24, bold, Anton font)
- Subtle horizontal rule between rows
- Top rows (11, 10 pts) get brighter glow than bottom rows
